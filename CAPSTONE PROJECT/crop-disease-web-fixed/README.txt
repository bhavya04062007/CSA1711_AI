CROPCare AI - Simple Crop Disease Detection Webpage

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the folder.
2. Open index.html in a browser.

For VS Code:
1. Open the folder in VS Code.
2. Install the "Live Server" extension (optional).
3. Right-click index.html.
4. Select "Open with Live Server".

Features:
- Home page
- Disease Detection page
- Image upload and preview
- Demo prediction result clearly labeled as demo
- Disease information
- Prediction History with search/filter
- About page
- Model performance placeholder
- Responsive mobile layout

Important:
The prediction shown on the Detection page is DEMO DATA only. It is not a real AI prediction yet.

Later, the real PlantVillage + CNN/MobileNetV2 model can be connected to this webpage.
